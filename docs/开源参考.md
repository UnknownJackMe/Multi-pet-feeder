# 开源参考

本项目不会依赖单一开源项目，而是分别吸收多个项目中已经验证过的设计经验。

## 1. Metropolia-Smart-Pet-Feeder/smart-pet-feeder

主要参考：

- ESP32-S3 / ESP-IDF 工程结构；
- 组件化硬件驱动；
- EventBus 风格解耦；
- HX711 食盆称重；
- RFID 组件边界；
- 电机控制；
- MQTT / 配网 / 本地 UI。

不直接照搬：

- RC522 / 13.56 MHz RFID 不适合我们当前宠物通道读距需求；
- 我们的双门和防尾随安全要求更严格。

## 2. Alex-ala/OpenCatFlap

主要参考：

- 通道控制思路；
- 两侧独立状态机；
- 方向感知；
- 光幕 / 门洞检测；
- 避免简单的 `RFID -> open` 逻辑。

我们的适配：

- 改为外门 + 认证缓冲舱 + 内门；
- 内门作为食物访问的安全边界。

## 3. Tech-RW/Catfeeder

主要参考：

- 多宠不同饮食隔离；
- 宠物 RFID；
- 机械位置确认；
- “执行器命令不等于真实物理状态”的工程原则。

## 4. hb9ezs/meowpass

主要参考：

- 宠物 RFID 硬件；
- 电源轨隔离；
- 电源噪声对读取距离的影响；
- PCB 与 RFID 天线设计。

## 5. s60sc/ESP32_RFID_Reader

主要参考：

- 125 kHz / 134.2 kHz RFID；
- FDX-B 宠物植入芯片；
- 天线调谐和读取距离。

后续可以通过统一 backend 同时支持项圈 Tag 与植入芯片。

## 6. Michael-Rolle/Arduino-Automatic-RFID-Cat-Feeder

主要参考：

- 上电归零；
- 限位开关确认门状态；
- 断电后的机械状态恢复。

## 7. Honeysad007/RFID-Cat-Feeder

主要参考：

- 多猫 RFID 喂食器实际行为；
- IR 存在检测；
- RFID 重复读取过滤；
- 缓慢、低惊扰的舵机运动；
- 执行器高噪声阶段必要时暂停 RFID 读取。

## 8. Catcierge

主要参考：

- 可测试的 FSM 架构；
- 将识别与门控制决策分开；
- 使用模拟 / 测试工具覆盖通道场景。

## 许可证原则

本仓库为 Apache-2.0。

部分参考项目采用 GPL 系列许可证，因此本项目默认：

- 学习其架构和设计思想；
- 不直接复制 GPL 源码；
- 独立重写实现；
- 如需真正引入第三方代码，必须先单独确认许可证兼容性。
