# 系统架构

## 项目目标

构建一套面向多宠家庭的三通道自动喂食器，支持 2 只猫 + 1 只狗分别使用自己的粮，并具备：

- 宠物身份识别；
- 双门防尾随；
- 定量称重出粮；
- 本地离线运行；
- 故障安全；
- 可选远程监控与视觉辅助。

## 总体结构

```text
三路独立粮仓
  ├─ 寿司
  ├─ 椰子
  └─ 蓝莓
        ↓
独立出粮电机
        ↓
共享称重食盆
        ↓
进食舱
        ↑
内门
        ↑
身份认证 / 防尾随缓冲舱
  ├─ RFID 身份识别
  ├─ 多区 ToF 占用检测
  ├─ 地板称重
  ├─ 外门 / 内门光幕
  └─ 可选摄像头
        ↑
外门
```

## 安全模型

系统对“食物访问”采用 **Fail-Closed（默认拒绝）**，对“宠物机械安全”采用 **Fail-Safe（优先解除夹持风险）**。

核心规则：

- 身份不确定 → 内门保持关闭；
- 怀疑存在多只宠物 → 内门保持关闭；
- 门口有遮挡 → 禁止继续关门，必要时反向打开；
- 门的真实状态必须由限位开关确认，不能把执行器命令当成物理状态；
- Wi-Fi / MQTT / NUC / 摄像头失效时，本地喂食逻辑仍能工作；
- 重启不能导致同一餐重复完整出粮。

## 控制架构

ESP32-S3 是整机的权威本地主控。

```text
ESP32-S3
  ├─ 事件总线 EventBus
  ├─ 宠物身份服务
  ├─ Presence Fusion 在场信息融合
  ├─ Access Control 双门访问状态机
  ├─ Door Controller 门控
  ├─ Hopper Controller ×3 出粮通道
  ├─ Bowl Scale 食盆称重
  ├─ Chamber Scale 缓冲舱称重
  ├─ Scheduler / RTC 定时调度
  ├─ Fault Manager 故障管理
  └─ MQTT / Web 遥测（非安全关键）
```

NUC / Camera 仅作为可选辅助系统，V1 不允许把关键安全逻辑依赖到视觉或网络上。

## 防尾随工作流程

双门缓冲舱按“小型气闸”工作，硬约束是：

```text
外门和内门绝不能同时处于物理开启状态
```

标准进入流程：

1. 检测宠物靠近外门；
2. RFID 识别到有权限的宠物；
3. 打开外门；
4. 确认宠物进入缓冲舱；
5. 确认外门门槛区域已清空；
6. 关闭外门，并由关闭限位确认；
7. 再次核验缓冲舱：
   - 已锁存有效授权身份；
   - ToF 估计只有一只宠物；
   - 地板重量符合该宠物合理范围；
   - 外门和内门光幕均清空；
   - 关键传感器健康且数据新鲜；
8. 打开内门；
9. 确认宠物进入进食舱；
10. 关闭内门；
11. 才进入正式进食状态。

任何关键证据不一致，都终止本次通行，不做“多数票猜测”。

## 传感器融合

主要安全信号：

- RFID：回答“是谁”；
- VL53L5CX 8×8 ToF：回答“舱里有几个目标、在哪里”；
- 缓冲舱 Load Cell + HX711：回答“总重量是否合理”；
- 外门光幕：判断外门门槛是否被占用；
- 内门光幕：判断内门门槛是否被占用；
- 四个限位开关：确认两扇门的真实开 / 关状态。

可选信号：

- Camera 宠物检测 / 计数；
- NUC 端 Pet ReID。

V1 中 Camera 不能作为安全决策的必要条件。

## 三通道出粮

每个粮仓拥有独立执行机构：

```text
粮仓 -> 螺杆 / 转盘 -> 落粮管 -> 共享称重食盆
```

出粮采用称重闭环，而不是单纯依赖电机运行时间：

1. 食盆称重稳定 / 去皮；
2. 快速粗出粮；
3. 接近目标重量后降低速度或脉冲出粮；
4. 达到容差范围后停止；
5. 电机动作但重量长期不增加 → 判断可能卡粮；
6. 短暂反转后重试；
7. 超过最大重试次数后锁存故障。

## V1 硬件基线

- ESP32-S3 N16R8 ×1
- DS3231 RTC ×1
- NEMA17 ×3
- TMC2209 ×3
- 5 kg Load Cell + HX711 ×1（食盆）
- 20 kg Load Cell + HX711 ×1（缓冲舱）
- VL53L5CX ×1
- 红外 / 对射光幕 ×2
- RFID Reader ×1
- 宠物 RFID Tag ×3
- 双门执行器 ×2
- 开 / 关限位开关 ×4
- 12 V 主电源 + 5 V 逻辑电源

## 开源参考

本项目只借鉴各项目中成熟的设计思想，不依赖单一项目作为架构真值源：

- Metropolia Smart Pet Feeder：ESP32-S3 组件化架构、事件总线、称重、RFID、电机、MQTT；
- OpenCatFlap：通道感知、方向判断、多状态机、门禁逻辑；
- Tech-RW/Catfeeder：多宠饮食隔离、RFID、机械位置确认；
- MeowPass：宠物 RFID、电源噪声与天线设计；
- ESP32_RFID_Reader：125 / 134.2 kHz RFID 与 FDX-B；
- Michael-Rolle RFID Cat Feeder：上电归零、限位确认、断电恢复；
- Honeysad007 RFID Cat Feeder：多猫 RFID、红外保持、缓慢关门。

## V1 暂不实现

- 原生手机 App；
- 云端依赖控制；
- 强依赖视觉才能授权；
- 自动洗碗；
- 成品级工业外壳；
- 处方粮级“零串粮”保证。
