# 安全与故障模型

本项目会控制宠物周围的机械门，因此安全行为必须从架构阶段就定义，而不是最后再补。

## 1. 安全优先级

1. 避免夹住、困住或挤压宠物；
2. 防止未授权宠物接触食物；
3. 避免重复 / 错误出粮；
4. 尽量保证系统可用和可远程观测。

发生冲突时，高优先级目标覆盖低优先级目标。

## 2. 硬约束

### S-001 双门互锁

```text
NOT (outer_open AND inner_open)
```

外门和内门绝不能同时处于物理打开状态。

### S-002 内门授权条件

只有以下条件全部满足，内门才允许开始打开：

```text
已知且授权的宠物
AND 有效喂食会话
AND 外门已确认关闭
AND 内门当前已确认关闭
AND 外门光幕清空
AND 内门光幕清空
AND 缓冲舱 == 一只合理宠物
AND 缓冲舱重量匹配该宠物
AND 关键传感器健康且数据新鲜
```

### S-003 防夹响应

对应门正在关闭时，如果门槛被遮挡：

1. 停止继续关门；
2. 明确反向 / 打开，解除夹持力；
3. 当前通行授权失效；
4. 不允许沿用原授权直接继续通行。

### S-004 物理反馈优先

门状态来自限位开关或其他经过验证的物理反馈，不来自历史命令。

### S-005 矛盾限位属于故障

同一扇门出现：

```text
open_limit == true && closed_limit == true
```

必须按故障处理。

### S-006 重启不得重复整餐出粮

重启可以中断一餐，但不能把账本清零后自动再出完整一份。

## 3. Fail-Closed 与 Fail-Safe

### 食物授权：Fail-Closed

身份或占用证据有歧义时，保持内门关闭。

### 宠物机械安全：Fail-Safe

如果宠物可能处于门口，而门安全状态不确定，应优先解除关闭力并向“不夹宠物”的方向恢复。

因此 `SAFE_FAULT` 不等价于“把所有门强制关上”。

## 4. 传感器健康度

关键传感器必须同时提供：

- 当前值；
- 健康状态；
- 时间戳 / 新鲜度。

过期数据不能当作当前有效数据使用。

关键传感器包括：

- 授权阶段的 RFID；
- 外门运动期间的外门光幕；
- 内门运动期间的内门光幕；
- 缓冲舱验证阶段的 ToF；
- 缓冲舱称重；
- 两扇门的开 / 关限位；
- 出粮过程中的食盆称重。

## 5. 尾随威胁模型

必须考虑：

- 授权宠物进入后第二只紧跟；
- 第二只只伸头或前半身进门；
- 两只宠物在 ToF 上重叠成一个目标；
- 只读到一个 RFID，但实际有两只宠物；
- 授权 Tag 在门边，但真正进入的是另一只宠物；
- 授权宠物在关门时退回去；
- 宠物长时间停留在缓冲舱；
- 宠物推 / 顶正在运动的门；
- 某个传感器短暂掉线。

RFID 只能证明身份，不能证明物理空间里只有一只宠物。

## 6. 门本地安全层

每扇门的底层控制器都应独立实现：

- 运动超时；
- 开 / 关限位确认；
- 矛盾限位检测；
- 光幕触发时立即停止 / 反向；
- 接近行程末端时降低速度（执行器允许时）；
- 禁止无限自动重试顶压宠物。

机械结构建议：

- 轻质门板；
- 圆角 / 软边；
- 低力连杆或限扭结构；
- 适当机械顺应性。

## 7. 断电恢复

非正常断电后启动：

1. 不相信持久化的门位置；
2. GPIO 先进入不驱动的安全状态；
3. 移动前先读取限位和光幕；
4. 门口有人时，不允许执行穿过宠物区域的归零动作；
5. 恢复并核对喂食账本；
6. 建立真实门状态；
7. 全部通过后才进入 `IDLE`。

UPS 只提升可用性，不能替代正确的恢复逻辑。

## 8. RFID 电气可靠性

要求：

- 电机 / 舵机大电流不要和 RFID 模拟电源共用未经滤波的路径；
- Reader 附近增加去耦；
- RFID 天线尽量远离步进电机和舵机线束；
- 使用真实宠物项圈姿态验证三维有效读卡区域；
- 必须测试执行器运行时的 RFID 可靠率，而不是只测静态桌面环境。

如果读距无法覆盖实际通道几何，应更换 Reader / 天线，而不是依靠上层软件“补救”。

## 9. 出粮故障

重点故障：

- 螺杆旋转但重量不增加；
- 重量增加过快或异常；
- 食盆本来就有未记账粮食；
- 食盆称重不稳定 / 掉线；
- 电机驱动过热 / 堵转；
- 选错粮仓。

出粮重试必须有次数和时间上限，绝不能无限运行等待达到目标重量。

## 10. 真宠物参与前必须完成的测试

- 双门归零；
- 限位故障；
- 关门过程光幕遮挡；
- 每种门状态下切断电源；
- 矛盾传感器输入；
- 使用两个重物模拟尾随；
- ToF 占用歧义；
- 称重断线 / 数据冻结；
- 出粮卡死；
- 断网。

完成台架测试后，再做全程有人看护的宠物实测。

## 11. 无人值守门槛

“离家 1–3 天无人值守”不是 V1 默认能力，必须经过验收：

- 大量有人看护的成功运行；
- 防夹可靠率有统计数据；
- RFID 读取可靠率有统计数据；
- 出粮精度有统计数据；
- 长时间 soak test；
- 重启 / 断电恢复测试；
- 卡粮恢复测试；
- 日志 / 遥测复盘；
- 机械磨损、尖锐边缘和夹点检查。

是否允许无人值守要由可测量的验收结果决定，而不是由设计意图直接宣称。
