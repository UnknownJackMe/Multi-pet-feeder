# 硬件清单

## 1. 主控与供电

- ESP32-S3 N16R8 ×1
- DS3231 RTC ×1
- 12 V 5 A 电源适配器 ×1
- 12 V → 5 V、≥5 A DC-DC 降压模块 ×1
- 保险丝 + 保险丝座 ×1
- 总电源开关 ×1

## 2. 三通道出粮

- NEMA17 / 42 mm 步进电机 ×3
- TMC2209 UART 步进驱动 ×3
- 2–4 L 食品级粮仓 ×3
- 螺杆 / 转盘出粮机构 ×3
- 电机联轴器 ×3
- 食品级 PP 或 304 不锈钢落粮管 ×3

## 3. 食盆称重

- 5 kg Load Cell ×1
- HX711 ×1
- 304 不锈钢宠物碗 ×1

## 4. 身份识别

V1 基线：

- 125 kHz 中距离 RFID Reader ×1
- EM4100 / TK4100 项圈 Tag ×3

后续可选：

- 134.2 kHz FDX-B Reader，用于读取宠物植入芯片。

注意：RFID 供电应尽量和步进电机 / 舵机电源隔离并做好滤波，避免执行器噪声降低读距。

## 5. 防尾随缓冲舱

- VL53L5CX 8×8 多区 ToF ×1
- 红外 / 光电对射传感器 ×2
- 20 kg Load Cell ×1
- HX711 ×1

缓冲舱称重主要用于“占用合理性判断”，不作为兽医级体重秤。

## 6. 双门系统

- 门执行器 ×2
- 开 / 关限位开关 ×4
- 轻质 PC / 亚克力门板 ×2
- 导轨 / 连杆机构 ×2
- 硅胶防夹软边

原型执行器候选：

- MG996R：适合早期机构验证；
- 减速电机 / 线性执行器：如果最终门机构需要更稳定的力和位置控制再升级。

门安全不能只依赖“舵机力气不大”。

## 7. 可选视觉系统

- 1080P UVC USB 摄像头 ×1
- 5 V 补光灯 ×1
- NUC / Linux 主机 ×1（已有则直接复用）

视觉只做辅助，不是 V1 的安全必要条件。

## 8. 最小传感器集合

```text
RFID Reader ×1
RFID Tag ×3
VL53L5CX ×1
门槛光幕 ×2
5 kg Load Cell ×1
20 kg Load Cell ×1
HX711 ×2
限位开关 ×4
DS3231 ×1
```

## 9. 食品接触材料建议

长期直接接触宠物粮的部件优先使用：

- 304 不锈钢；
- 食品级 PP；
- 食品级硅胶。

普通 PLA / PETG 更适合：

- 电机支架；
- 传感器支架；
- 外壳；
- 导轨固定件。
