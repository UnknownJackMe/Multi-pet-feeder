# 开发路线图

## 阶段 0：架构冻结

交付物：

- 系统架构基线；
- V1 硬件基线；
- 防尾随状态机；
- 开源参考映射；
- 安全硬约束。

退出条件：

- 门、传感器、身份识别、出粮之间不存在未解决的逻辑矛盾。

## 阶段 1：桌面硬件原型

在做完整外壳之前先把所有硬件放在桌面上独立验证。

目标：

- 稳定读取 3 个 RFID Tag；
- 读取 VL53L5CX 占用数据；
- 标定食盆和缓冲舱 Load Cell；
- 驱动两套门机构并用限位确认；
- 驱动三路出粮电机；
- 实现统一事件日志。

退出条件：

- 所有硬件都能独立测试；
- 不允许任何执行器状态只靠命令推测。

## 阶段 2：防尾随认证舱

目标：

- 实现外门 / 内门硬互锁；
- 接入 Access Control FSM；
- 测试授权宠物进入；
- 测试错误宠物拒绝；
- 测试双宠尾随拒绝；
- 测试门口遮挡恢复；
- 测试重启 / 归零恢复。

退出条件：

- 连续至少 100 次尾随模拟中，内门误开次数为 0；
- 任意光幕遮挡测试都不会继续向宠物方向施加关门力。

## 阶段 3：三通道闭环出粮

目标：

- 三粮仓独立控制；
- 基于重量的闭环出粮；
- 粗 / 精两阶段出粮；
- 卡粮检测；
- 反转有限次数重试；
- 持久化喂食账本。

退出条件：

- 重复出粮精度达到约定标准；
- 重启不会导致已经完成的同一餐再次完整出粮。

## 阶段 4：整机集成

目标：

- 合并认证舱与出粮系统；
- 每只宠物独立喂食策略；
- RTC 本地定时；
- 断网运行；
- 遥测与故障上报。

退出条件：

- Wi-Fi 完全断开时仍能完成完整喂食流程；
- 错误宠物不能通过正常进入或尾随路径接触另一只宠物的粮。

## 阶段 5：可选视觉

目标：

- USB Camera + NUC；
- YOLO 宠物计数；
- 进食会话录像；
- Pet ReID 实验。

约束：

- 除非后续经过专门架构评审，否则视觉始终只是辅助信息，不进入核心安全链。

## 阶段 6：产品化

目标：

- 定制 PCB；
- 优化门机构；
- 食品级机械结构；
- 更安静的执行器；
- 备用电源；
- 可维护 / 可拆洗设计；
- 工业设计外壳；
- 长时间无人值守验收。
